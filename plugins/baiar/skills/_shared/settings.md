# Налаштування плагіна — `.claude/baiar.local.md`

> **Лише довідка.** Це не скіл. Описує файл налаштувань плагіна `baiar` на рівні проєкту:
> де він лежить, як створюється і що означає кожен ключ.

## Чому окремий файл

У `my-toolkit` свій файл `.claude/my-toolkit.local.md` (ключ `interview_depth`), у `sdlc` —
`.claude/sdlc.local.md`. Якби `baiar` писав у чужий файл, той плагін знайшов би його вже наявним,
не дописав би своїх ключів і мовчки працював би на значеннях за замовчуванням. Тому в кожного
плагіна — свій файл.

## Створення, якщо файлу немає

Файл створюється **автоматично** на початку `ba-discovery` (фаза 1). **Ідемпотентно:** якщо файл
уже є, його читають і ніколи не перезаписують.

1. Якщо `.claude/baiar.local.md` немає — запиши frontmatter нижче, а під ним розділ «Що робить
   кожен ключ» як тіло файлу, щоб файл документував сам себе.
2. **Допиши `.gitignore`** (створи, якщо немає): рядок `.claude/*.local.md`. Якщо такий шаблон
   уже є — нічого не додавай.
3. Скажи аналітику: «Створив `.claude/baiar.local.md` зі значеннями за замовчуванням — відредагуй
   його, щоб змінити поведінку плагіна».

## Frontmatter, що записується у файл

```yaml
---
discovery_depth: medium    # easy | medium | hard — глибина за замовчуванням для ba-discovery (див. _shared/discovery-depth.md)
---
```

## Що робить кожен ключ

- **`discovery_depth`** — `easy | medium | hard`. Значення за замовчуванням для регулятора
  глибини `ba-discovery`. Воно лише **підсвічує** рекомендовану опцію в першому питанні —
  аналітик усе одно може змінити рівень на конкретне інтерв'ю або передати `--depth=`, щоб
  пропустити питання. На повноту підсумку не впливає. Повний опис →
  [`discovery-depth.md`](./discovery-depth.md).

Нові ключі додаються сюди в одному місці, разом із поясненням.
