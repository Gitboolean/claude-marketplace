# Налаштування плагіна — `.claude/my-toolkit.local.md`

> **Лише довідка.** Це не скіл. Описує файл налаштувань плагіна `my-toolkit` на рівні проєкту:
> де він лежить, як створюється і що означає кожен ключ.

## Чому окремий файл, а не `.claude/sdlc.local.md`

Плагін `sdlc` веде свій файл `.claude/sdlc.local.md` з ~15 ключами для `implement-tasks`. Якби `my-toolkit` створював той самий файл лише з `interview_depth`, `sdlc:implement-tasks` знайшов би його вже наявним, не дописав би своїх ключів і мовчки працював би на значеннях за замовчуванням. Тому в кожного плагіна — свій файл.

## Створення, якщо файлу немає

Файл створюється **автоматично**, щойно він уперше знадобиться скілу (зазвичай `write-prd` на кроці 1). **Ідемпотентно:** якщо файл уже є, його читають і ніколи не перезаписують.

1. Якщо `.claude/my-toolkit.local.md` немає — запиши його: frontmatter нижче, а під ним — розділ «Що робить кожен ключ» як тіло файлу, щоб файл документував сам себе.
2. **Допиши `.gitignore`** (створи, якщо немає): рядок `.claude/*.local.md` — ці файли особисті для кожного розробника і не комітяться. Якщо такий шаблон уже є — нічого не додавай.
3. Скажи користувачу: «Створив `.claude/my-toolkit.local.md` зі значеннями за замовчуванням — відредагуй його, щоб змінити поведінку плагіна».

## Frontmatter, що записується у файл

```yaml
---
interview_depth: medium    # easy | medium | hard — глибина за замовчуванням для write-prd і clarify-prd (див. _shared/interview-depth.md)
---
```

## Що робить кожен ключ

- **`interview_depth`** — `easy | medium | hard`. Значення за замовчуванням для регулятора глибини в `write-prd` і `clarify-prd`: скільки скіл вирішує сам, а скільки питає (кількість питань, самостійність). Воно лише **підсвічує** рекомендовану опцію в першому питанні про глибину — користувач усе одно може змінити рівень на конкретний запуск або передати `--depth=`, щоб пропустити питання. На повноту AC **не** впливає (це мінімум на будь-якому рівні). Повний опис → [`interview-depth.md`](./interview-depth.md).

Нові ключі додаються сюди в одному місці, разом із поясненням.
